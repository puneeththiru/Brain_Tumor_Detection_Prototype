BT-Tracker

This is a no-cost website that allows users to detect and classify potential brain tumors in T1 MRI scans. Segmentation results assist users in tumor annotations for export.

Please upload an MRI image to analyze.

Note: The analysis may take a few seconds, so please be patient. Model loading automatically starts when you enter the page. The image should be in a supported format (e.g., PNG, JPEG).

Disclaimer: This website is for educational and annotation assistance purposes only and should not be used for medical diagnosis or treatment. Always consult a healthcare professional for medical advice.

The models were trained on the BRISC2025 dataset, which contains roughly 5,000 training images and 1,000 validation images.
