BTDetection

This is a no-cost website that allows users to detect and classify potential brain tumors in T1 MRI scans. Segmentation results assist users in tumor annotations for export. Alternate between 2D MRI and NIFTI analysis.

2D MRI: Please upload an MRI image to analyze. This is used for single slice analysis.

NIFTI Viewer: For nifti analysis, click nifti viewer and upload an nii/nii.giz file. If you work with Dicoms, please convert to nifti before uploading. Near the top of the website, click on "DICOM to NIFTI Converter" to convert.

Note: The analysis may take a few seconds, so please be patient. Model loading automatically starts when you enter the page. The image should be in a supported format (e.g., PNG, JPEG).

Disclaimer: This website is for educational and annotation assistance purposes only and should not be used for medical diagnosis or treatment. Always consult a healthcare professional for medical advice. The classifier detects between glioma, meningioma, pituitary, or no tumor.

Transparency: This website does not use user uploaded files to train its models. Private patient information is not used by the website, but the website should still be used responsibly and NOT be taken as 100% truth.

The models were trained on the BRISC2025 dataset, which contains roughly 5,000 training images and 1,000 validation images.
